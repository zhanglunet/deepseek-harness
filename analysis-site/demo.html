左边渲染出来的每一条，都来自右边这段日志事件——这正是「可重建性」那一章讲的： 模型看到的一切都能从日志重建。

数据来源：examples/headless-agent/tests/snapshots/<场景>/stream-json.expected.jsonl， 即仓库中提交的快照期望输出。它们由 DSH_SNAPSHOT=record 对真实 API 录制生成，此后作为 golden 供无密钥回放比对。

已被规范化的字段：会话 id、工作目录、时间戳、系统提示词、工具 schema 与 token 计数在提交前会被替换为占位符或归零， 所以本页不展示 token 数字，它们在 golden 里不是真实值。文本内容、工具名、参数与结果是原样的。

本页不做什么：不连接任何模型 API，不接受也不存储任何密钥，不在服务端执行任何代码。 想真正跑起来，一条命令就够：npx @deepseek-ai/dsh web。
